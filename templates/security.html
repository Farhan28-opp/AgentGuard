06

Risk analysis and containment

Hard authority rules run first and are never overridden by the model. An IsolationForest then scores requests that are already within limits; HIGH risk revokes the agent's capability subtree, releases its holds and suspends its key.

07

Cryptographic identity and verification

Each agent holds its own Ed25519 keypair; only public keys are stored. Signed requests are checked for signature, ±300 s timestamp window, one-time nonce, payload hash and operation binding. Capability grants are re-verified on every refresh.
